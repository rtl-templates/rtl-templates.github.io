How the 52-week money challenge works

Each week you save the number of the week in dollars: $1, then $2, then $3, up to $52 in the last week. The first months are easy and build the habit. If December is tight, do it in reverse and start with $52 in January instead. Missed a week? Pick any open amount that fits and tick it off. Set up an automatic transfer on payday to make it effortless.
